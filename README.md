# EventNova

EventNova is a comprehensive Android application designed to streamline event management, organization administration, and attendee booking. Built with Java and Android Studio, it connects event organizers with attendees in a seamless mobile experience.

## ✨ Features

- **Multi-Role System:** Secure access tailored for Users (Attendees), Organizers, and Administrators.
- **User Booking & Management:** 
  - Users can browse events, book tickets, and view their personalized "My Bookings" list.
  - Automatically generates detailed Booking Bills.
- **Organizer Dashboard:** 
  - Organizations can register, create, edit, and manage their events.
  - Track organization-specific bookings, attendees, and view sales statistics.
- **Admin Control Panel:** Dedicated dashboard for platform administrators to monitor users, organizers, and all event bookings.
- **User & Organization Profiles:** Built-in tools for individuals and event companies to manage their profiles and details.
- **Local Database:** Powered by a robust SQLite (`DatabaseHelper`) local storage implementation.

## 🛠 Tech Stack

- **Platform:** Android (Java)
- **IDE:** Android Studio
- **Storage:** SQLite Database
- **UI Architecture:** Recycler Views for dynamic lists (Events, Bookings, Users, Orgs).

## 🚀 Getting Started

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/YourUsername/EventNova.git
   ```
2. **Open in Android Studio:** Open the `EventNova` folder in Android Studio.
3. **Sync Requirements:** Allow Gradle to sync and download the required dependencies.
4. **Run the App:** Click the `Run` button or press `Shift + F10` to launch EventNova on an emulator or a physical device.
